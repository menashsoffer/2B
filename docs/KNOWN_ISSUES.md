# Known Issues & Locked Behaviors (רשימת התנהגויות קיימות נעולות)

מסמך זה מתעד התנהגויות חישוב קיימות, קצוות חריגים (Edge-cases) ואי-דיוקים היסטוריים שננעלו במכוון בתוך בדיקות המאפיינות (Characterization Tests) במסגרת שלב 0.

> [!WARNING]
> **כלל ברזל לרה-פקטורינג:** התנהגויות אלו נשמרות **כפי שהן** לאורך כל תהליך הרה-פקטורינג המבני כדי להבטיח אפס שינוי התנהגות (Zero Behavior Change). כל תיקון יבוצע אך ורק **לאחר סיום הרה-פקטורינג המלא**, כשינוי עצמאי ומאושר בנפרד.
> כל סעיף להלן מקושר ישירות לשם הבדיקה המאפיינת הנועלת אותו (ולא למספרי שורות שעלולים להשתנות במהלך הרה-פקטורינג).

---

## 1. מחשבון השוואת רכבים (Car Comparison Calculator)

### 1.1 קיצוץ עלות חודשית נטו ל-0 (Net Monthly Cost Clamped to 0)
- **בדיקה מאפיינת נועלת:** `car_netCostClampedToZero_whenResaleExceedsTotalCost`
- **ההתנהגות שננעלה:** כאשר מחיר המכירה לאחר 5 שנים (`resaleValueAfter5Years`) שווה לעלות הכוללת (`total5YearCost`) או עולה עליה (כך ש-`net5YearCost <= 0`), ה-`netMonthlyCost` ננעל קשיחה על `0.0`.
  ```kotlin
  val netMonthlyCost: Double
      get() = if (net5YearCost > 0) net5YearCost / 60.0 else 0.0
  ```
- **ההשפעה:** במקרה של רכב נדיר/אספנות שערכו עלה או שרווח המכירה מכסה את כל עלויות האחזקה, החישוב אינו מציג רווח חודשי שלילי (חיסכון נקי), אלא 0.
- **סטטוס:** נעול בבדיקות מאפיינות; יטופל רק לאחר סיום הרה-פקטורינג.

### 1.2 קיצוץ הפרש חודשי מול רכב בסיס לכיוון האפס (Truncation Toward Zero via `toInt()`)
- **בדיקות מאפיינות נועלות:** 
  - `car_baselineDiff_savingTruncationTowardZero_locksCurrentOutput`
  - `car_baselineDiff_expensiveTruncationTowardZero_locksCurrentOutput`
- **ההתנהגות שננעלה:** ההפרש החודשי `(diffFromBaseline / 60.0)` נקצץ לכיוון האפס (`truncation toward zero`) באמצעות `.toInt()`, ולא מעוגל (rounding).
  - לדוגמה: הפרש של `15.9` ש״ח מקוצץ ל-`15` ש״ח (ולא מעוגל ל-16).
  - הפרש של `-15.9` ש״ח מקוצץ ל-`-15` ש״ח.
- **ההשפעה:** אי-התאמה קלה של שקל בודד בין הסך הכולל ל-5 שנים המחולק ב-60 לבין המספר המוצג כחודשי.
- **סטטוס:** נעול בבדיקות מאפיינות; יטופל רק לאחר סיום הרה-פקטורינג.

### 1.3 חישוב צריכת דלק כאשר צריכת הדלק שווה ל-0 (Zero Km Per Liter Fallback)
- **בדיקה מאפיינת נועלת:** `car_energyHelper_fuelZeroKmPerLiter_locksZeroFallback`
- **ההתנהגות שננעלה:** אם מוזן ערך `0` בק״מ לליטר, הפונקציה מחזירה `0.0` במקום להציג שגיאה או אינסוף (`Infinity`).
  ```kotlin
  if (kml > 0) (km / kml) * fuelPrice else 0.0
  ```
- **סטטוס:** נעול בבדיקות מאפיינות.

### 1.4 ברירת מחדל 1.0 לשדה ק״מ/ליטר ריק שמנפחת עלות דלק (Empty Km/Liter Falls Back to 1.0)
- **בדיקה מאפיינת נועלת:** `car_energyHelper_emptyKmPerLiterFallbackToOne_locksInflatedFuelCost`
- **ההתנהגות שננעלה:** כאשר שדה הק״מ לליטר נמחק לחלוטין או מכיל מחרוזת לא חוקית, הקוד מבצע fallback לערך `1.0`:
  ```kotlin
  val kml = kmPerLiter.toDoubleOrNull() ?: 1.0
  ```
  כתוצאה מכך התנאי `kml > 0` מתקיים והחישוב מבוצע כ-`(annualKm / 1.0) * fuelPrice`, מה שמנפח את עלות הדלק השנתית באופן קיצוני (למשל: 20,000 ק"מ ב-7.5 ש"ח לליטר מניבים 150,000 ש"ח לשנה במקום 0 או סימון קלט חסר).
- **ההשפעה:** עלות דלק שנתית מנופחת פי כמה וכמה עד שהמשתמש מקליד ערך מלא.
- **התיקון המיועד בעתיד (Intended Future Fix):** בשדה ק״מ/ליטר ריק או לא תקין — לא יבוצע חישוב כלל, ובמקום זאת יוצג הטקסט **"הזן צריכה"** (ולא 0 או חישוב מנופח).
- **סטטוס:** נעול בבדיקות מאפיינות; יתוקן רק לאחר סיום הרה-פקטורינג כשינוי מבוקר ומאושר.

## 2. מחשבון פנסיה וחיסכון (Pension & Savings Calculator)

### 2.1 אחוז תשואה כאשר סך ההפקדות הוא 0 (Zero Deposits Profit Percent)
- **בדיקה מאפיינת נועלת:** `pension_zeroDeposits_locksZeroProfitPercent`
- **ההתנהגות שננעלה:** כאשר `totalDeposits <= 0.0`, התשואה מוגדרת כ-`0.0%` כדי למנוע חלוקה באפס, גם אם השווי הנוכחי חיובי (`currentValue > 0`).
  ```kotlin
  val profitPercent: Double
      get() = if (totalDeposits > 0.0) ((currentValue - totalDeposits) / totalDeposits) * 100.0 else 0.0
  ```
- **סטטוס:** נעול בבדיקות מאפיינות.

## 3. מחשבון מנויי AI (AI Subscriptions Calculator)

### 3.1 המרה שנתית לחודשית בחלוקה פשוטה ב-12
- **בדיקות מאפיינות נועלות:** 
  - `aiSubscription_usdMonthly_locksCurrentOutput`
  - `aiSubscription_usdYearly_locksCurrentOutput`
- **ההתנהגות שננעלה:** 
  - מנוי שנתי מחולק ב-`12.0` לקבלת עלות חודשית.
  - מנוי חודשי מוכפל ב-`12.0` לקבלת עלות שנתית.
  - החישוב אינו מתחשב בהנחות שנתיות בפועל מול חיוב חודשי או בעמלות המרת מט"ח של חברות האשראי.
- **סטטוס:** נעול בבדיקות מאפיינות.
