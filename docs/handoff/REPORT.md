## Tests

New: 64 unit tests. `ImportFileTest` 9, `ImportTextTest` 8, `StatementParsersTest` 18, `ImportMergeTest` 15, `ClassifyTest` 11, `ImportDocumentsTest` 3. They run on 14 synthetic fixtures under `app/src/test/resources/import/`, generated by `tools/import-fixtures/make_fixtures.py` (openpyxl, with LibreOffice for the real BIFF8 .xls files). Every name and number in them is made up.

- Claude sandbox, pure-JVM run of the money engine and importer sources: `tests 128, failures 0, errors 0`. That is 64 existing engine tests plus 64 new ones.
- Rules in the Firestore emulator: `tests 25, pass 25, fail 0`. That is 22 existing tests, 2 new collections in the per-collection loop, and 1 test for a full document, an oversized one and a bad id.
- Full `testDebugUnitTest`: this runs in the branch CI (`.github/workflows/branch-tests.yml`), because the sandbox has no Android SDK. See the PR for the run.

No test was disabled, skipped or loosened, and no guard allow-list changed. Every file is under 300 lines.

## Library choice and APK size

There is no new dependency. xlsx and xlsm are read with `java.util.zip` and SAX, and .xls with a small OLE2 and BIFF8 reader. Apache POI would add several MB and needs StAX on Android. jxl is unmaintained. The source is about 25 KB, so the APK delta should be tens of KB. It has not been measured, because the release build is not run on branches.
