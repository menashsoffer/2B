# ביקורת חוויית משתמש — Myself

בסיס הבדיקה: `origin/main` בקומיט `253b7ce`; ניתוח סטטי ותמונות בדיקה קיימות. מסמך זה מתעד גם מגבלות ואינו אישור להתנהגות בזמן ריצה.

## מפת האפליקציה כפי שהיא בפועל

- בית: כרטיס כסף → כסף; כרטיסי חלומות, קניות ומעקב → שלוש לשוניות בהכנה; אווטאר → גיליון חשבון → הגדרות / משק בית. `HomeContent.kt:82–126`, `AppShell.kt:106–145`.
- הגדרות → גלריית מסכים ישנים: בית ישן, משימות, חלומות ישנים, עוד, אינבוקס, כושר, יומן וקטלוג. משק בית נגיש גם ישירות מגיליון החשבון. המסכים הישנים מפנים בחלקם זה לזה. `GalleryIndex.kt:47–54`, `SettingsDialog.kt:294`, `AppNavHost.kt:66–98`. בגרסה שנבדקה מסלולי המחשבונים הישנים שהוזכרו בבריף אינם רשומים ב־NavHost; אין להניח שנגישים.
- כסף → החודש: ייבוא ישיר; התחלה בהכנסה כשאין תוכנית; עודף ותוכנית, קבוצות נפתחות ועריכת פריט; תנועות / לא משויכות; סגירת חודש; הוספה → בחירת סוג / ייבוא → עורך → היקף שינוי או אישור מחיקה. `MoneyContent.kt:112–231`, `MoneyEditorSheet.kt:80–175`.
- כסף → התמונה הגדולה: נכסים והתחייבויות ועריכתם; כרית וחיסכון; האם אפשר? → עורך יעד / אישור מחיקה; מעשרות → הגדרות / תרומה / מחיקה / קישור לתנועות; רכב → קטגוריות / טופס השוואה; פנסיה → עורך קרן / מחיקה; מנויים → עורך מנוי. `BigPictureContent.kt:64–170`.
- תנועות → בחירת חודש ומסנן → גיליון קטגוריה או מקור הכנסה / אישור הסרת תנועה ממתינה. סגירת חודש → קובץ חסר / סימון שאין חיובים, תנועות, עריכת יתרה ישנה, סגירה או אישור סגירה מחדש. ייבוא → בוחר קבצים מערכתי → סקירה → גיליון קטגוריה לכל בית עסק → אישור → מסך הצלחה. שיתוף קובץ חיצוני פותח כסף וייבוא. `MoneyScreen.kt:103–149,185–201`; `AppShell.kt:82–86`.
- תתי המסכים בכסף אינם יעדי ניווט עצמאיים אלא מצבי ViewModel בסדר עדיפות קבוע; סרגל הלשוניות נשאר במעטפת. חזרה ממעשרות דרך תנועות ומסגירה דרך ייבוא תוכננה באמצעות שכבות אלה; שחזור לאחר סגירת תהליך, סיבוב ומעבר לשונית לא אומת בפועל.

## מסעות משתמש J1–J11

שיטת ספירה: מתחילים בבית, סופרים הקשות ניווט, בחירות ושמירה; לא סופרים הקלדה, גלילה, פתיחת מקלדת או צעדי ממשק של בוחר הקבצים שמשתנים בין מכשירים. אלה אומדנים מהקוד, לא מדידות שימוש. `N` בתי עסק שדורשים החלטה; `E` הוצאות; `M` חודשים לאחור. ספירת השדות/תנאים אינה כלולה; החזרה נספרת כשנדרשת למסע.
